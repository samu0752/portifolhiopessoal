# Portfólio de Samuel Xavier Sampaio

Site pessoal para apresentar minha formação em Análise e Desenvolvimento de Sistemas, conhecimentos e busca por estágio em suporte técnico ou desenvolvimento.

## Acessos

- [Abrir o site publicado](https://samu0752.github.io/portifolhiopessoal/)
- [LinkedIn](https://www.linkedin.com/in/samuel-sampaio-169a08271/)
- [Currículo público em PDF](curriculo-samuel-sampaio-publico.pdf)

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- Sem dependências ou etapa de compilação

## Conteúdo

Apresentação, conhecimentos em desenvolvimento e fundamentos de TI, formação acadêmica, cursos, experiência profissional e contato. A página não usa foto nem exibe telefone diretamente.

## Executar localmente

Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP estático.

## Arquivos

- `index.html`: página e estilos responsivos.
- `curriculo-samuel-sampaio-publico.pdf`: currículo com links para GitHub, LinkedIn e portfólio.

## Publicar no GitHub Pages

Coloque estes arquivos na raiz do repositório `samu0752/portifolhiopessoal`, preservando a configuração atual do GitHub Pages. O site publicado ficará em https://samu0752.github.io/portifolhiopessoal/.
